# 10. Scripts npm

| Script | Descripción |
|--------|-------------|
| `npm run dev` | Servidor de desarrollo (<http://localhost:4321>) |
| `npm run build` | Build de producción (`dist/`) |
| `npm run preview` | Preview del build con Astro |
| `npm run cf:preview` | Preview simulando Cloudflare Pages (Wrangler) |
| `npm run cf:deploy` | Build + deploy manual a Pages |
| `npm run ci` | Alias de build (para pipelines) |

Los scripts se definen en `package.json`. Ver también [Inicio rápido](Inicio-rapido) y [CI/CD](CI-CD).
